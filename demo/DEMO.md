# KAEKURU デモ手順

モックモード（`DATABASE_URL` なし）で動かします。**全ステップ画面操作だけ**（端末コマンド不要）。

主役タグ = **`demo-token-123`**。同梱の QR:

| ファイル | 中身 | 用途 |
|---|---|---|
| `qr-demo-token-123-lan.png` | `http://192.168.11.5:3000/t/demo-token-123` | スマホでスキャン |
| `qr-demo-token-123-localhost.png` | `http://localhost:3000/t/demo-token-123` | 同じ Mac の QR リーダー / カメラ |
| `qr-demo-token-activated-*.png` | 2個目の持ち物用（`demo-token-activated`） | 任意 |

---

## 0. 起動 & リセット

既存のサーバーが 3000 番を掴んでいたら止める:

```bash
lsof -ti tcp:3000 | xargs kill
```

**スマホでデモするなら本番ビルドを使う**（`next dev` は毎画面の初回コンパイルで数秒待たされ、ボタンが「効かない → 2回タップ」に見える）:

```bash
cd ~/KAEKURU
rm -rf tmp .next
npm run demo:build     # ALLOW_MOCK_DB=1 next build
npm run demo           # ALLOW_MOCK_DB=1 next start -H 0.0.0.0 -p 3000
```

`rm -rf tmp` でモック状態が消え、起動時に `demo-token-123`(未登録) / `demo-token-activated`(登録済み) がシードし直されます。やり直すたびに `rm -rf tmp` → `npm run demo`（再ビルド不要）。

- **スマホで試す**: Mac と同じ Wi-Fi。`-lan` 版 QR。初回接続で macOS のファイアウォール許可が出たら「許可」。IP が違うときは末尾「QR を作り直す」。
- **Mac だけで試す**: `-localhost` 版 QR、または URL 直打ち。

ログインしたまま QR を読んでも届け出フォームは出る（拾得者フローはログイン非依存）ので、**スマホ1台で①〜⑥通し**でできます。

---

## 1.【拾得者】未登録タグをスキャン

`qr-demo-token-123` をスキャン → `/t/demo-token-123` が開く → **「未登録」** と表示されて終了（持ち主情報・持ち物名は一切出ない）。

---

## 2.【持ち主】ログインして持ち物を登録

1. `http://192.168.11.5:3000/` →「ログイン」→ **`test` / `test`**
2. 持ち物が0件なので **登録画面に自動遷移**
3. QRトークン `demo-token-123` / 名前「黒い長財布」→「登録する」
4. （郵送も試すなら）完了後「受取拠点を登録」→ 拠点名「渋谷郵便局」/ 住所「東京都渋谷区渋谷1-1-1」/ 受取人名「カエクル 太郎」→「保存」。試さないなら「あとで」

---

## 3.【拾得者】再スキャン → 届け出

1. `qr-demo-token-123` を再スキャン → 今度は **「登録済み / 持ち物: 黒い長財布」**
2. 「届け出る」→ 届け方を選ぶ
   - **どこかに届ける**: 場所「渋谷駅前交番」→（任意）メモ・写真 →「送信する」
   - **郵送する**: 匿名お届け先（渋谷郵便局 留め / 住所 / 受取人）が表示 →「送信する」
     - 持ち主の自宅住所・電話は一切出ない
3. **完了画面**に遷移 → **受付番号 `FND-XXXXX`** が大きく表示（郵送なら同梱メモの案内も）

---

## 4.【拾得者】受け取り先を登録（報酬を受け取る場合）

完了画面の **「受け取り先を登録する」** → 名前（例「拾い 花子」）を入力 →「紐付けする」。
これで拾得者が **報酬対象**になります（登録しなければ匿名完了で報酬なし）。

---

## 5.【持ち主】通知を確認 → 受け取り確認

1. ナビ「マイページ」→ 持ち物カードに **「未読 1」**
2. 「通知」→ **「「黒い長財布」の落とし物が届け出られました」** ＋ 届け方（手渡し（渋谷駅前交番）/ 郵送（渋谷郵便局 留め））・メモ・受付番号・日時
3. **「受け取りを確認」** を押す
   - 拾得者が受け取り先を登録済み → 「報酬 ¥1,000 を用意しました」
   - 匿名のまま → 「報酬はありません」

> 手順 4（拾得者の登録）と手順 5（受け取り確認）はどちらが先でも OK。後から登録した場合も報酬が作られます。

---

## 6.【持ち主】報酬を送る

ナビ「報酬」→ **¥1,000 / 送金待ち**（送り先: 拾い 花子）が出る → **「報酬を送る」** → **送金済み** になる。

（この段階では実際の送金はしません。Stripe Connect 等の実装は別ステップ。）

---

## やり直し（リセット）

サーバーを止めて（Ctrl+C）:

```bash
rm -rf tmp
npm run demo
```

---

## QR を作り直す（IP が違う / 別ポート）

`IP` は自分の LAN IP（`ipconfig getifaddr en0`）。

```bash
IP=$(ipconfig getifaddr en0)
npx qrcode -o qr.png "http://$IP:3000/t/demo-token-123" -w 600
```
