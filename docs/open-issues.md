# 未解決の論点

## 1. 「その他」ケースの連絡手段

フォーム形式のみでは持ち主↔拾得者の往復連絡ができない。イレギュラー対応が必要な場合、一方向 or 簡易往復メッセージ機能が必要か検討が必要。

- 選択肢A: 「その他」を選んだ場合のみ簡易な一往復メッセージ機能を用意する
- 選択肢B: 「その他」は運営が個別対応する窓口として割り切る

## 2. 対面受け渡し(「どこかに届ける」)の受け取り確認

現状は持ち主の自己申告のみで報酬(送金)が発生する設計。不正防止レベルをどこまで求めるか。

- 選択肢A: 自己申告のみで確定させる(シンプルだが不正リスクあり)
- 選択肢B: 拾得者側にも「渡しました」ボタンを用意し、両者確認で確定させる

## 3. 局留め期限切れ時の荷物の扱い

差出人情報がない匿名発送のため、期限切れ荷物が返送されず郵便局側で処分される可能性がある。

- 対応方針の検討が必要(例: 期限が近づいた際のリマインド強化、期限切れ前提での運用ルール明文化など)
