# 拾得者フロー(ログイン不要)

全体像は `docs/overview.md` を参照。

## フロー図

```
QRスキャン → GET /t/:token
  ├─ 未登録(status=unactivated) → 「まだ使われていません」で終了
  └─ 登録済み(status=active)   → フォーム画面へ

フォーム画面
  ├─ 届け方選択
  │    ├─ どこかに届ける
  │    │     └─ 届けた場所を入力(施設名 or 住所) → 送信
  │    └─ 郵送する
  │          └─ 匿名お届け先(局留め)を表示
  │                (郵便局名・住所・受取人名・受付番号)
  │              → 発送 → 「発送完了」ボタンで報告
  ├─ (任意)写真添付・発見場所入力
  └─ 送信後、ログイン導線を表示
        ├─ 受け取り先を登録する → お礼を受け取れる(持ち主が直接送金)
        └─ 登録しない → 匿名のまま完了(お礼なし)
```

## 画面ごとの補足

### QRスキャン直後
- タグが `unactivated` の場合は即終了(個人情報も何も表示しない)
- タグが `active` の場合のみフォームへ進む

### 届け方フォーム
- **どこかに届ける**:施設名 or 住所のテキスト入力のみ。本人確認や照合の仕組みは現状なし(→ `docs/open-issues.md` 参照)
- **郵送する**:匿名お届け先(局留め)の発行ロジックは `docs/anonymous-mail.md` を参照。拾得者が見るのは「局名・住所・受取人名・受付番号」のみで、持ち主の自宅住所は一切露出しない
- 写真添付・発見場所は任意項目。位置情報取得は都度許可を求める

### 送信後のログイン導線
- ログインなしで完結できることが必須。ログインを強制しない
- 未ログインで完了した場合でも、`case_code`(受付番号)を控えておけば後からログインして紐付け可能(`POST /api/return-cases/:id/link-finder`)

## 関連するAPI

- `GET /t/:token` — QRスキャン時の状態確認
- `POST /api/return-cases` — フォーム送信
- `POST /api/return-cases/:id/ship` — 郵送の発送完了報告
- `POST /api/return-cases/:id/link-finder` — 後からのログイン紐付け

詳細は `docs/api.md` を参照。
